# 验收清单

公开仓库的账单、持仓、人物及 OCR 测试样例均为虚构数据。以下已勾选项描述现有自动测试覆盖；在自己的环境中发布前仍应重新运行测试和构建。

## 可自动验证

- [x] Swift 包可构建。
- [x] 共享内核与桥接单元测试全部通过。
- [x] 咔皮表头按字段映射，调整列顺序仍可读取；缺少必要字段时明确报错。
- [x] 虚构的四笔样例包含两笔收入和两笔支出，其中各一笔不计入收支；合计只包含计入记录。
- [x] 疑似重复提示保留第一笔、标记后续副本，并支持按指纹出现次数增量导入，不直接删除原流水。
- [x] 重叠或首尾相邻的账单覆盖区间可以合并；不连续区间不会跨空档合并，而是保留结束日期较新的连续区间并提示用户。
- [x] 贷款本金、内部转账、投资买卖、不计入和重复流水不进入长期生活支出。
- [x] 退款只在唯一匹配原消费后回到原月份冲减；不规则支出与月度中位数年化规则有单元测试。
- [x] 资产净值包含全部现金并扣除未偿负债本金。
- [x] 资产快照冻结实际使用的 USD/CNY、HKD/CNY 数值、来源、观测日期、获取时间和新鲜度；后续汇率缓存变化不改写历史快照。
- [x] 3%、3.5%、4% 目标及预计日期可追溯到输入。
- [x] PII 清洗测试覆盖手机号、邮箱、卡号、账号、证件号且保留商户。
- [x] 非 ChatGPT 登录、API Key 环境、Schema 错误和中断均有明确错误。
- [x] 配对单元测试验证双方 Curve25519 协商得到相同六位 SAS、确认消息证明、长期凭据保护、重连双向证明，以及未认证设备无法使用业务通道。
- [x] 虚构 OCR 样例覆盖产品名称与市值列配对、跨行名称、噪声过滤，以及港股代码补零。

可选 XLSX 集成检查通过环境变量 `FIRE_KAPI_FIXTURE` 指定本机自行准备的测试账单，验证导入结果的计数、指纹及重复引用一致性；未设置时跳过。仓库不包含个人账单或个人账单的对照合计，请勿将其上传至公开 Issue 或测试日志。

## 需要完整 Xcode

- [x] 生成 Xcode 工程并通过 iOS 17+ 与 macOS 14+ 构建。
- [ ] 真机离开 60 秒后 Face ID 锁定，60 秒内不重复打扰。
- [ ] iPhone 与 Mac 首次配对时显示相同六位 SAS；用户在两端人工核对并于 iPhone 确认。短码不一致、重连证明错误和删除凭据均符合预期。
- [ ] Mac 菜单栏应用能启动本机 App Server；月报与追问不进入 Codex 任务列表，桥接重启后仍能从本机脱敏上下文连续追问。
- [ ] Mac 离线、额度不足和输出 Schema 错误不改变任何本地财务数据。
- [ ] 加密备份可导出，并可在仍保留原 Keychain 密钥的同一台 iPhone 上恢复。
- [ ] 无效、损坏或来自其他设备密钥的备份不会覆盖现有数据。
