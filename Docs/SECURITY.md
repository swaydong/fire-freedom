# 隐私与桥接安全边界

## 默认边界

- 账单、资产、负债、汇率缓存和 FIRE 结果保存在 iPhone 本地 SwiftData 容器。
- 离开应用超过 60 秒后，重新进入需要设备所有者认证。
- 资产截图只交给设备端 Vision，处理后立即释放，不保存原图。
- 本机备份使用 AES-GCM 和保存在 Keychain 的设备密钥；恢复前先完整解密、校验引用关系，再由用户确认替换。
- 备份不设置密码，只能在仍保留原 Keychain 密钥的同一台 iPhone 上恢复。
- 首版不启用 CloudKit，不向任何分析、广告或遥测服务发送数据。
- Mac 不在线、Codex 不可用或额度不足，只会让 AI 功能失败，不影响本地账本和计算。

## Codex 认证与进程

- 桥接程序先执行 `codex login status`，只接受明确的 `Logged in using ChatGPT`。
- 启动子进程前移除 `OPENAI_API_KEY` 与 `CODEX_API_KEY`。
- 认证错误不会回退到 OpenAI Platform API。
- App Server 只使用 stdio，不监听局域网或公网。
- 每个报告线程使用独立空目录；线程为只读沙箱、从不请求批准。
- 显式关闭 Web、shell、浏览器、应用连接器、多智能体、MCP、插件、技能发现和工作区依赖。
- 报告和追问都使用 JSON Schema 约束输出；Schema 不匹配视为失败，不保存半成品。
- 汇率请求不进入 Codex。Mac 桥接只向固定的 ECB HTTPS 数据接口发送快照日期和所需币种，不发送金额、持仓、负债名称或用户身份；失败时由 iPhone 直连同一官方接口或使用本地缓存。

## 手机与 Mac

- MultipeerConnectivity 会话要求加密。
- 运行 Mac 桥接会启动局域网发现与 TCP 重连监听，Bonjour 可向同一网络暴露设备名称和稳定设备标识；服务不应通过路由器转发到公网。首次配对需要用户打开配对窗口并核对短码，已配对设备通过持有凭据完成重连。
- 首次配对时 Mac 与 iPhone 分别生成 Curve25519 临时密钥，并把双方设备 ID、公钥及随机数纳入同一协商记录。两端从共享密钥独立计算并显示相同的六位 SAS 短码，短码不会作为单方口令传输或输入。
- 用户跨两端人工核对 SAS；一致时只需在 iPhone 确认，不一致则取消。iPhone 的确认带有共享密钥证明，Mac 通过已认证的 AES-GCM 消息下发长期随机凭据，长期凭据只存双方 Keychain。
- 重连时双方把新的 Mac 随机数和 iPhone 随机数纳入 HMAC 证明：iPhone 先证明持有长期凭据，Mac 返回挑战证明，iPhone 再响应，最后由 Mac 给出认证完成证明。任一证明无效或过期都会拒绝连接。
- 未完成双向认证的设备不能发送业务请求；认证完成后，业务消息使用从长期凭据和本次上下文派生的安全通道密钥。每个请求还包含协议版本与请求 ID，响应只发回当前已认证会话中的请求设备。
- 第二阶段可在用户自行安装 Tailscale 后增加私有地址连接；不会开放公网端口。CloudKit 私有同步同样留在第二阶段，需具备付费 Apple Developer 权限后再启用。

## 发送前清洗

`AnalysisPacketV1` 保留交易日期、收支、金额、分类、商户/备注、资产结构、负债和 FIRE 指标。发送前清除或替换：

- 姓名和常见“转给某人”模式中的个人部分；
- 银行卡、账号、身份证件号码；
- 手机号、电子邮箱；
- 连续长数字和可能包含账号的查询串。

清洗后的商户信息仍可能属于敏感消费数据。生成报告前 UI 必须显示将发送的数据范围，并由用户主动确认。

## 产品身份校验

- 资产截图仍只在 iPhone 上由 Vision 读字，原图不发送给产品目录。
- Mac 向 OpenFIGI 只发送产品代码和推断出的交易市场；不会发送截图、持仓金额、平台、账号或用户身份信息。
- 公开版内置本地目录为空，不携带 FinanceDatabase 个人化子集或 HKEX 补丁。开发者可通过目录接口注入具有再分发权限的数据，必须保留来源、版本、许可及日期。
- AKShare 只作为显式配置后的可选兜底；未安装或不可用时不会阻断 OpenFIGI、本地目录、账本或 FIRE 计算。东方财富基金搜索接口可进一步提供产品候选，只接收产品查询，不接收持仓金额或账户信息。
- 有截图代码时，所有校验失败都必须保留原代码并要求确认，禁止退回名称搜索后改写成另一个产品。

## 日志与报告安全问题

系统日志中的连接诊断和 Codex 错误详情标记为私密，仍应在分享诊断文件前检查设备名、文件路径及财务内容。PII 清洗依赖规则，不能保证识别任意姓名或自由文本中的全部敏感信息；用户发送前应检查数据范围。漏洞请使用[私密报告入口](../.github/SECURITY.md)，不要把真实账单、截图、密钥或备份上传到公开 Issue。

## 汇率联网边界

- Mac 桥接只接受 CNY、USD、HKD 三种币种，并固定访问 ECB Data Portal；请求方不能传入自定义网址。
- 新版 iPhone 先通过旧版也支持的 `ping` 探测 `exchange-rates-ecb-v1` 能力，旧版 Mac 不会收到无法识别的新消息，因此升级不需要重新配对。
- 汇率响应继续通过已认证的 AES-GCM 业务通道返回，并写入 iPhone 本地缓存；桥接程序不保存个人汇率请求历史。

## 删除

新月报和追问使用不会写入 Codex 任务列表的临时线程，完成后立即取消订阅。Mac 仅保存已经过 PII 清洗的数据包、结构化报告和问答上下文，用于桥接重启后的恢复；删除报告时一并清除这些本机记录。旧版本留下的持久 Codex 线程仍按原协议显式删除，不能伪装成远端已删除。
